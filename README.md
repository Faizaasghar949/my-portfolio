# Personal Portfolio Website

A responsive personal portfolio website built from scratch using HTML5, custom CSS, and Bootstrap 5. It includes a hero section, about me, education, skills, projects, contact form, and footer.

## Features
- Responsive Bootstrap 5 navbar and grid layout
- Bootstrap cards, badges, buttons, progress bars, and form components
- Custom CSS styling and local SVG illustrations
- Contact form that prepares an email using the visitor's default email application
- Responsive layout for desktop, tablet, and mobile

## Project structure
```text
my-portfolio/
├── index.html
├── style.css
├── README.md
└── images/
    ├── profile.svg
    ├── project-portfolio.svg
    ├── project-hostel.svg
    └── project-store.svg
```

## Run locally
Open `index.html` in a browser. An internet connection is needed to load Bootstrap 5 from its official CDN.

## Before submission
1. Replace `Your Name` and all bracketed education details with your own information.
2. Replace `your.email@example.com` in `index.html` with your email address (including the `mailto:` target in the form script).
3. Update the project descriptions and links to your real work.
4. Add your GitHub profile link where appropriate.
5. Test the page on mobile and desktop.
